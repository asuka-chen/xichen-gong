# xichen-gong
# 飞机大战：Roguelike 局内成长版

**一款融合弹幕射击、随机技能成长与元素组合机制的 HTML5 游戏。**

## 游戏简介

驾驶战机进入不断变化的战场，击落敌机、收集资源、解锁技能，并通过元素组合构建独特的战斗流派。

每局开始时，命运之轮会随机赋予玩家一项增益和一项减益。随着战斗推进，敌人逐渐增强，玩家需要不断调整策略，利用技能协同与元素反应突破挑战，迎战拥有不同攻击机制的强大 Boss。

## 核心特色

- **五种射击模式**：标准速射、重型加农、霰弹散射、蓄能光炮、追踪导弹。
- **五种终极技能**：核爆脉冲、时间冻结、绝对防御、贪婪掠夺、机械军团。
- **Roguelike 局内成长**：通过升级随机选择技能，强化伤害、射速、暴击、生存能力与弹幕效果。
- **五种元素构筑**：火、冰、毒、光、暗；每局最多选择三种不同元素。
- **元素连锁反应**：热震爆、霜毒、净化、蚀日、狱火，让不同元素之间产生战术联动。
- **命运之轮**：每局随机获得增益与减益，改变当局的战斗节奏。
- **多类型 Boss**：挑战弹幕地狱、激光、冲锋者、召唤者和护盾者。
- **资源与临时强化**：收集经验、金币、治疗、护盾和各类临时增益，争取战斗优势。

## 如何游玩

**电脑端操作**

- `W / A / S / D` 或方向键：移动
- `空格`：射击；蓄能光炮模式下可长按蓄力
- `J`：释放已充能的终极技能
- `P`：暂停或继续游戏

**移动端操作**

使用屏幕左侧虚拟摇杆移动，右侧区域持续射击，并通过对应的触屏区域使用大招或暂停。

## 项目目标

本项目围绕“每局都能构建不同的战斗方式”展开，尝试将经典飞机大战与 Roguelike 成长、元素反应和 Boss 机制结合起来，让玩家在躲避弹幕与持续输出之间做出选择。

## 技术实现

- HTML5
- CSS
- JavaScript
- Canvas 2D

当前版本为浏览器运行的游戏原型。后续可以继续围绕战斗平衡、元素组合深度、Boss 阶段机制、特效表现与移动端体验进行迭代。

**项目类型：** 单机弹幕射击 / Roguelike / 浏览器游戏
