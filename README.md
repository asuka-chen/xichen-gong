✈️ 飞机大战：Roguelike 局内成长版
一款使用 HTML5 Canvas、CSS 和原生 JavaScript
制作的浏览器飞机大战原型。玩家可以选择初始射击模式与终极技能，在不断出现的敌机和
Boss 弹幕中生存，通过击杀、收集经验和升级来构筑自己的战斗流派。
项目形式： 单个 HTML 文件，无需安装依赖或启动后端服务。
当前入口文件： plane_fixed(8).html（建议在 GitHub 仓库中重命名为
index.html，方便通过 GitHub Pages 直接访问）。

🎮 游戏特色
- 五种射击模式：从稳定速射到重型加农、霰弹散射、蓄能光炮和追踪导弹，选择适合自己的输出方式。
- 五种终极技能：核爆脉冲、时间冻结、绝对防御、贪婪掠夺和机械军团，提供不同的清场、生存与成长策略。
- Roguelike
  升级构筑：击败敌人获取经验并升级，从随机强化中选择技能，逐步打造本局配置。
- 五种元素体系：火、冰、毒、光、暗。每局最多选择 3
  种不同元素，围绕元素状态与组合反应形成流派。
- 元素共鸣反应：搭配元素触发额外战斗效果，让构筑选择影响实际战斗表现。
- 多种敌机与 Boss：敌机具有不同的移动与攻击方式；Boss
  包含弹幕地狱、激光、冲锋者、召唤者和护盾者等类型。
- 命运之轮：每局加入增益与减益，让不同对局产生变化。
- 战斗资源与成长：包含经验、金币、治疗、火力增幅、移速提升、磁力、护盾和冻结等拾取物。
- 桌面与触屏操作：支持键盘操作，并为移动端提供触控操作区域。
🕹️ 开始游戏
方式一：本地运行
1. 下载或克隆本仓库。
2. 使用浏览器打开 plane_fixed(8).html。
3. 在开始界面选择射击模式和终极技能，然后开始游戏。
游戏为前端单文件原型，通常不需要安装 Node.js、配置数据库或启动后端服务。
方式二：通过 GitHub Pages 在线游玩
1. 将游戏文件上传到 GitHub 仓库。
2. 将入口文件重命名为 index.html。
3. 打开仓库的 Settings → Pages。
4. 在部署设置中选择从分支部署，选择默认分支和根目录（/），然后保存。
5. 等待 GitHub Pages 完成部署，使用页面显示的网址访问游戏。
如果你保留了 plane_fixed(8).html 这个文件名，也可以通过对应的 HTML
文件路径访问；将其命名为 index.html 通常更适合作为项目主页。

⌨️ 操作说明
电脑端
  操作           按键
  移动飞机       W / A / S / D 或方向键
  射击           按住空格键
  释放终极技能   J
  暂停 / 继续    P
蓄能光炮需要按住射击键蓄力，并在合适的时机松开发射。
手机 / 触屏端
使用游戏画面中的虚拟摇杆移动飞机，并通过触控操作区域进行持续射击、释放终极技能和暂停。具体按钮位置以游戏界面为准。
🔫 射击模式
  模式       特点
  标准速射   射速快，输出稳定，适合持续攻击
  重型加农   射速较慢，但单发伤害高
  霰弹散射   扇形发射 5 发弹丸，适合近距离覆盖
  蓄能光炮   按住蓄力，松开发射；蓄力等级会影响攻击表现
  追踪导弹   自动追踪目标，降低瞄准压力
💥 终极技能
  技能       效果
  核爆脉冲   对全屏敌人造成高额伤害
  时间冻结   冻结普通敌机与弹幕 3 秒；Boss 不受冻结影响
  绝对防御   获得 5 秒无敌效果
  贪婪掠夺   8 秒内获得双倍经验与金币
  机械军团   召唤 4 架无人机协助战斗
🧪 元素构筑与反应
每局最多选择 3
种不同元素。元素升级会施加对应状态，并可通过特定组合产生额外效果。
  反应名称   元素组合   机制概述
  热震爆     火 + 冰    目标处于燃烧与减速状态时触发范围爆炸
  霜毒       冰 + 毒    目标中毒并减速时强化毒伤
  净化       毒 + 光    通过光元素引爆毒素
  蚀日       光 + 暗    光标记可触发暗影伤害
  狱火       暗 + 火    暗影标记可触发额外伤害与点燃效果
元素反应的具体触发条件、数值和持续时间以游戏当前实现为准。
👾 敌人与 Boss
普通敌机
游戏包含侦察、突击、狙击、重型和自爆等敌机类型。不同敌机会采用直线、正弦、停走或追踪等移动模式，部分敌机会进行远程攻击或自爆。
Boss 类型
- 弹幕地狱：以密集弹幕压迫玩家走位。
- 激光：使用激光攻击与扫射机制。
- 冲锋者：通过蓄力和冲刺制造威胁。
- 召唤者：召唤小型敌机并配合弹幕攻击。
- 护盾者：利用旋转护盾阻挡玩家子弹。
📈 升级与拾取
升级候选涵盖多个方向，例如：
- 输出：伤害强化、射速强化、子弹数量、子弹穿透、暴击率、暴击伤害、子弹体积。
- 生存：最大生命值、即时治疗、吸血效果。
- 机动与技能：移动速度、终极技能充能、子弹弹射。
- 元素强化：提升火、冰、毒、光、暗相关能力。
- 战场拾取物：治疗包、火力增幅、疾步、经验、金币、磁力、护盾和时间冻结。
此外，命运之轮会提供本局增益与减益。例如经验获取提升、额外金币、子弹速度提升、敌人生成加快、移动速度降低或敌方弹速增加等。玩家需要根据当局效果调整战术。
🧰 技术实现
- HTML5：游戏页面与界面结构
- CSS：开始界面、技能选择卡片、操作提示及视觉样式
- JavaScript：游戏状态、玩家与敌机逻辑、升级系统、元素反应、Boss
  行为和触控输入
- Canvas 2D：游戏场景、角色、子弹、特效与战斗 UI 的实时绘制
- requestAnimationFrame：驱动游戏画面更新循环
游戏目前以单文件原型形式组织，便于快速运行、分享和迭代。
